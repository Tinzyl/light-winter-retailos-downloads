# Light Winter RetailOS

## Product Name

The commercial product name is **Light Winter RetailOS**.

## Company Mark

Use **Light Winter Technologies** as the company/producer mark across:

- splash/loading screens
- activation and licensing screens
- owner dashboard
- settings/about screen
- receipt footer
- backup/export footer
- fiscal setup and diagnostics
- generated reports

## Positioning

Light Winter RetailOS is a premium retail operating platform built for African retail realities: offline-first sales, branch control, serious inventory, strict random-token licensing, fiscal readiness, and clean cross-device operations from tuckshops to growing chains.

## Fiscal Product Language

Fiscalisation must never appear as guessed or complete without authority/provider documentation. When the product reaches that stage, show:

`Fiscal Integration Stage Reached - Upload Fiscal API Documentation / Credentials to Continue.`
