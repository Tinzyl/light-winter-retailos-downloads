# Light Winter RetailOS

## Bhuku Diki Rekushandisa

### 1. Kutanga App

Muridzi ndiye anogadzira shop.

1. Vhura app.
2. Dzvanya **Create New Shop as Owner**.
3. Nyora zita re shop, branch, phone, ne address.
4. Gadzira owner name, username, ne PIN.
5. Kana muine ma branch akawanda, wedzera ma branch.
6. Kana wagadzirira, wedzera vashandi.
7. Dzvanya **Create Shop**.

Mushure mezvo, device inoda license.

### 2. Kuisa License

Phone, SUNMI, kana computer imwe neimwe inoda license yayo.

1. Pa license screen, copy **Device ID**.
2. Tumira Device ID ku Light Winter Technologies.
3. Uchapiwa license voucher.
4. Nyora voucher mu app.
5. Dzvanya **Verify and Unlock Device**.

### 3. Kupinda mu App

1. Nyora username.
2. Nyora PIN.
3. Dzvanya **Login**.

Kana owner akanganwa login, dzvanya **Forgot owner username or PIN**.

### 4. Kuwedzera Vashandi

Izvi zvinoitwa ne owner kana admin ane full access.

1. Enda ku **Admin**.
2. Dzvanya **Add User**.
3. Nyora zita, username, role, ne PIN.
4. Sarudza zvaanobvumidzwa kuita.
5. Sarudza branch yaanoshanda pairi.
6. Dzvanya **Save**.

Mushandi anopinda ne username ne PIN yaakapihwa ne owner.

### 5. Kubatanidza Imwe Device

Izvi ndezveimwe phone, SUNMI, kana Windows computer.

1. Owner anoenda ku **Branches**.
2. Pa branch chaiyo, dzvanya **Copy Join**.
3. Tumira mashoko acho kumushandi.
4. Pa device itsva, dzvanya **Join Existing Shop / Branch**.
5. Nyora shop name, branch name, ne branch code.
6. Dzvanya **Join Device**.
7. Mushandi opinda ne username ne PIN yake.
8. Device iyoyo inofanira kuiswa license.

### 6. Kutengesa pa POS

1. Enda ku **POS**.
2. Tsvaga product name kana SKU.
3. Dzvanya product kuti ipinde mu cart.
4. Shandisa **+** kana **-** kuchinja quantity.
5. Dzvanya delete kubvisa item.
6. Sarudza currency: USD, ZWL, ZAR, kana BWP.
7. Dzvanya **Checkout and Record Payment**.
8. Sarudza payment: Cash, Card, Mobile Money, kana Debt.
9. Nyora discount kana iripo.
10. Nyora mari yabhadharwa.
11. Tarisa total, paid, change, ne debt.
12. Confirm sale.

App inongorekodha payment. Haibhadharisi card kana mobile money.

### 7. Vatengi Vakawanda

Kana paine vatengi vakawanda:

1. Mu **POS**, dzvanya **New Customer**.
2. Isa zvinhu zvemutengi iyeye.
3. Chinja pakati pevatengi pa customer selector.
4. Checkout mutengi apedza.

Ma cart asina kupera anogara kusvika wabuda mu app.

### 8. Receipt

Mushure me sale:

1. Sarudza **Print** kuprinta.
2. Sarudza **WhatsApp** kutumira receipt.
3. Nyora country code ne number, semuenzaniso `+263771234567`.
4. App inovhura WhatsApp pa number iyoyo.

SUNMI inoshandisa SUNMI printer kana iripo.

### 9. Stock

Enda ku **Stock**.

Kuwedzera product:

1. Dzvanya **Product**.
2. Nyora product name.
3. Nyora category.
4. Nyora price.
5. Nyora starting stock.
6. Nyora low stock level.
7. Sarudza supplier kana aripo.
8. Dzvanya **Save**.

Kuwedzera supplier:

1. Dzvanya **Supplier**.
2. Nyora supplier name.
3. Nyora phone ne notes kana zvichidiwa.
4. Dzvanya **Save**.

Ku import stock:

1. Dzvanya **Import**.
2. Sarudza CSV file.
3. File rinofanira kuva ne product name, category, SKU, price, stock, low stock, ne supplier.

Ku export stock:

1. Dzvanya **Export Stock**.
2. Sarudza **Save**, **Email**, kana **WhatsApp**.

Export iyi ndeye stock chete. Haitumire sales kana reports.

### 10. Branches

Enda ku **Branches**.

Owner anogona:

1. Kuwedzera branch.
2. Kugadzirisa branch.
3. Kudzima branch.
4. Ku copy branch join code.
5. Kuchinja branch.
6. Ku transfer stock.

Kana wachinja branch, sales ne stock zvinoshanda pa branch iyoyo.

### 11. Ku Transfer Stock

1. Enda ku **Branches**.
2. Sarudza branch iri kugamuchira stock.
3. Dzvanya **Transfer Stock**.
4. Sarudza branch iri kubvisa stock.
5. Tsvaga product.
6. Nyora quantity.
7. Dzvanya **Transfer**.
8. Confirm.

Stock inobviswa kune rimwe branch, yoiswa kune rimwe.

### 12. Void / Return

Shandisa izvi kana mutengi adzorera zvinhu kana sale yakanganiswa.

1. Enda ku reports kana sales list.
2. Vhura sale.
3. Dzvanya **Void / Return**.
4. Sarudza full void kana partial void.
5. Nyora reason.
6. Dzvanya **Record Void**.
7. Confirm.

Stock inodzokera ku branch. Reports dzinogadziriswa.

### 13. Reports

Enda ku **Home**.

Sarudza:

- **Daily**
- **Weekly**
- **Monthly**

Unogona kuona:

- Sales
- Transactions
- Debt
- Average sale
- User performance
- High performing stock
- Slow moving stock
- Voids and returns

Dzvanya **PDF / WhatsApp** kutumira report.
Dzvanya **Email** kutumira report ne email.
Dzvanya **Sync Cloud** kugadzirisa data kubva ku cloud.

### 14. Backup ne Recovery

Enda ku **Home**.

Shandisa:

- **Save JSON Backup**
- **Backup PDF**
- **Email Backup**

Chengeta owner recovery code zvakanaka.

Kurecover shop:

1. Vhura app.
2. Dzvanya **Recover Existing Shop as Owner**.
3. Nyora recovery code.
4. Nyora owner username ne PIN.
5. Dzvanya **Recover Shop**.

### 15. Fiscal Mode

Fiscal mode inoshandiswa kana shop ichida ZIMRA fiscalisation.

1. Enda ku **Admin** kana **Fiscal**.
2. Batidza fiscal mode.
3. Nyora company details.
4. Nyora TIN, VAT number, ZIMRA Fiscal Device ID, device serial, ne QR URL kana zvichidiwa.
5. Dzvanya **Save Company Details**.

Fiscal buttons:

- **Open Fiscal Day**
- **Close Fiscal Day**
- **Diagnostics**

Usatanga live fiscal sales usati waita ZIMRA testing ne approval.

### 16. Kubuda

Dzvanya logout icon.

Kana wabuda, unfinished working screens dzinobviswa.

### 17. Zvakakosha

- Owner ndiye anogadzira shop.
- Staff vanobatana ne branch code.
- Staff vanopinda ne username ne PIN kubva ku owner.
- Device imwe neimwe inoda license yayo.
- Internet inosync data pakati pema devices.
- Kana app yashandiswa offline, inosync kana internet yadzoka.
- Usape vanhu owner PIN.
- Chengeta recovery code zvakanaka.
