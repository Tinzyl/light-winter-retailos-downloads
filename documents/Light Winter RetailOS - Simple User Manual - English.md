# Light Winter RetailOS

## Simple User Manual

### 1. First Time Setup

Only the owner creates the shop.

1. Open the app.
2. Tap **Create New Shop as Owner**.
3. Enter shop name, branch name, phone, and address.
4. Create the owner name, username, and PIN.
5. Add branches if the shop has more than one branch.
6. Add users if ready.
7. Tap **Create Shop**.

After setup, the device must be licensed.

### 2. License Device

Each phone, SUNMI, or computer needs its own license.

1. On the license screen, copy the **Device ID**.
2. Send the Device ID to Light Winter Technologies.
3. Receive a license voucher.
4. Enter the voucher.
5. Tap **Verify and Unlock Device**.

### 3. Login

1. Enter username.
2. Enter PIN.
3. Tap **Login**.

If you forget owner login details, tap **Forgot owner username or PIN**.

### 4. Add Staff

Owner or full-admin only.

1. Go to **Admin**.
2. Tap **Add User**.
3. Enter name, username, role, and PIN.
4. Choose privileges.
5. Choose branch access.
6. Tap **Save**.

Staff must use the username and PIN made by the owner.

### 5. Join Another Device

For another phone, SUNMI, or Windows computer.

1. Owner goes to **Branches**.
2. Tap **Copy Join** on the correct branch.
3. Send the copied details to the staff device.
4. On the new device, tap **Join Existing Shop / Branch**.
5. Enter shop name, branch name, and branch code.
6. Tap **Join Device**.
7. Login using a username and PIN made by the owner.
8. License that device.

### 6. POS Sale

1. Go to **POS**.
2. Search product name or SKU.
3. Tap product to add it to cart.
4. Use **+** or **-** to change quantity.
5. Tap delete to remove an item.
6. Choose currency: USD, ZWL, ZAR, or BWP.
7. Tap **Checkout and Record Payment**.
8. Choose payment type: Cash, Card, Mobile Money, or Debt.
9. Enter discount if needed.
10. Enter amount paid.
11. Check total, paid, change, and debt.
12. Confirm sale.

The app records the sale. It does not process bank cards or mobile money.

### 7. Multiple Customers

Use this when many customers are at the counter.

1. In **POS**, tap **New Customer**.
2. Add items for that customer.
3. Switch between customers using the customer selector.
4. Checkout each customer when ready.

Unfinished carts stay until logout.

### 8. Receipt

After a sale:

1. Choose **Print** to print.
2. Choose **WhatsApp** to send receipt.
3. Enter country code and number, for example `+263771234567`.
4. The app opens WhatsApp for that number.

SUNMI devices use SUNMI print where available.

### 9. Stock

Go to **Stock**.

To add product:

1. Tap **Product**.
2. Enter product name.
3. Enter category.
4. Enter price.
5. Enter starting stock.
6. Enter low stock level.
7. Choose supplier if needed.
8. Tap **Save**.

To add supplier:

1. Tap **Supplier**.
2. Enter supplier name.
3. Enter phone and notes if needed.
4. Tap **Save**.

To import stock:

1. Tap **Import**.
2. Choose CSV file.
3. The file must have product columns like product name, category, SKU, price, stock, low stock, and supplier.

To export stock:

1. Tap **Export Stock**.
2. Choose **Save**, **Email**, or **WhatsApp**.

Stock export is stock only. It does not export sales or reports.

### 10. Branches

Go to **Branches**.

Owner can:

1. Add branch.
2. Edit branch.
3. Delete branch.
4. Copy branch join code.
5. Switch branch.
6. Transfer stock.

When you switch branch, sales and stock use that branch.

### 11. Transfer Stock

1. Go to **Branches**.
2. Choose the branch receiving stock.
3. Tap **Transfer Stock**.
4. Choose source branch.
5. Search product.
6. Enter quantity.
7. Tap **Transfer**.
8. Confirm.

Stock is removed from one branch and added to the other.

### 12. Void / Return

Use this when a customer returns goods or a sale must be corrected.

1. Go to reports or sales list.
2. Open the sale.
3. Tap **Void / Return**.
4. Choose full void or partial void.
5. Enter reason.
6. Tap **Record Void**.
7. Confirm.

Stock returns to the branch. Reports reduce correctly.

### 13. Reports

Go to **Home**.

Choose:

- **Daily**
- **Weekly**
- **Monthly**

You can view:

- Sales
- Transactions
- Debt
- Average sale
- User performance
- High performing stock
- Slow moving stock
- Voids and returns

Tap **PDF / WhatsApp** to share report.
Tap **Email** to email report.
Tap **Sync Cloud** to refresh cloud data.

### 14. Backup and Recovery

Go to **Home**.

Use:

- **Save JSON Backup**
- **Backup PDF**
- **Email Backup**

Keep the owner recovery code safe.

To recover a shop:

1. Open the app.
2. Tap **Recover Existing Shop as Owner**.
3. Enter recovery code.
4. Enter owner username and PIN.
5. Tap **Recover Shop**.

### 15. Fiscal Mode

Use fiscal mode only if the shop needs ZIMRA fiscalisation.

1. Go to **Admin** or **Fiscal**.
2. Turn on fiscal mode.
3. Enter company details.
4. Enter TIN, VAT number, ZIMRA Fiscal Device ID, device serial, and QR URL if required.
5. Tap **Save Company Details**.

Fiscal buttons:

- **Open Fiscal Day**
- **Close Fiscal Day**
- **Diagnostics**

Do not go live with fiscal mode until ZIMRA testing and approval are done.

### 16. Logout

Tap the logout icon.

Logout clears unfinished working screens.

### 17. Very Important

- Owner creates the shop.
- Staff join using branch code.
- Staff login with username and PIN from owner.
- Each device needs its own license.
- Internet syncs data across devices.
- Offline work syncs when internet comes back.
- Do not share owner PIN.
- Keep recovery code safe.
